# Security Policy

## Supported versions

Only the newest published version is supported.

## Reporting a vulnerability

Please open a GitHub issue without including secrets, credentials, or private account information. For a vulnerability that should not be public immediately, use GitHub's private vulnerability reporting feature when it is available for this repository.

PoE Personal Trade never needs a `POESESSID`, Path of Exile password, or browser cookie. A build asking for one of these values should not be trusted.
